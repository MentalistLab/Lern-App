# 🧠 Lern-Arena

Eine Lern-App ohne Installation: `index.html` im Browser öffnen – fertig.

- **300 Fragen** in 10 Kategorien (Geografie, Geschichte, Biologie, Physik & Chemie, Mathematik, Informatik, Deutsch, Englisch, Allgemeinwissen, Kunst & Kultur)
- **Fortschritt wird automatisch gespeichert** (im Browser, `localStorage`), inkl. Export/Import als JSON-Datei
- **10 Ränge** von Neuling bis Genie (XP, Kombo-Bonus, Perfekt-Bonus, Tagesziel)
- Modi: Kategorie-Quiz, Mix, Blitz (60 s), Fehler wiederholen
- Lernserie (Streak), Statistiken und 17 Erfolge
- Intelligente Fragenauswahl: Neues und Falsches kommt häufiger

Neue Fragen: in `questions.js` am **Ende** einer Kategorie anhängen
(`["Frage", "richtig", "falsch 1", "falsch 2", "falsch 3"]`).
